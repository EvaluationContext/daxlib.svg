# Viz

Quick-use visualization functions that wrap `DaxLib.SVG.Compound.*` with sensible defaults. These functions produce complete SVG data URIs ready for Power BI — just pass an axis column and a measure expression.

Each `DaxLib.SVG.Viz.*` function creates a self-contained chart with optional color and dimension overrides, making them ideal for sparklines and inline visuals in tables and matrices.
